## 下载 / Downloads

| 系统 | 文件 | 用法 |
|---|---|---|
| macOS 12+ (Apple Silicon & Intel) | `Ivynote-@VERSION@-macos-universal.dmg` | **推荐**。打开镜像并将 `Ivynote.app` 拖入「应用程序」文件夹。 |
| Windows 10/11 x64 | `Ivynote-@VERSION@-windows-x64-setup.exe` | **推荐**。双击安装，默认装到当前用户，无需管理员；升级直接装新版即可。 |
| Windows 10/11 x64 | `Ivynote-@VERSION@-windows-x64-portable.zip` | 免安装：解压后运行 `ivynote.exe`。 |
| Linux x86_64 | `Ivynote-@VERSION@-x86_64.AppImage` | 加可执行权限后双击运行（`chmod +x Ivynote-*.AppImage`）。需要 glibc ≥ 2.35（Ubuntu 22.04、Debian 12、Fedora 36 及更新）。 |

@MACOS_SIGNING_NOTE@ Windows 安装包暂未签名，SmartScreen 提示时点“更多信息 → 仍要运行”。Linux 上想加入应用菜单并自动更新，可用 [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) 或 AppImageLauncher 打开 AppImage。

校验：`SHA256SUMS.txt`。
